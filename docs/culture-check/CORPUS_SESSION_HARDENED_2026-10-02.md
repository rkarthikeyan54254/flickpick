# Culture Check hardened corpus session — 2026-10-02

This is the first corpus tranche curated on top of the evidence-derived v2 editorial pipeline. It is an internal operational tranche, not a consumer-facing batch number.

## Pipeline change applied first

Before adding titles, the publication system was hardened so new profiles require a durable `ResearchDossier`: film/source understanding, adversarial discovery queries, ten mandatory risk probes, evidence-linked findings, strongest counterevidence for high-risk claims, an independent red-team challenge, and explicit FACT / INTERPRETATION / INTENT separation.

Incomplete research now routes to `provisional-hold`. Human review is reserved for research-complete records with a materially unresolved high-risk contradiction. Medium confidence alone does not create a human bottleneck.

Chak De! India was migrated to the v2 model as the first regression case and remains Mixed / Contested + human-review because the Mir Ranjan Negi / Kabir Khan identity-source contradiction remains materially unresolved.
