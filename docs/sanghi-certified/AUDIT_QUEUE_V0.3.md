The purpose of this queue is to prevent editorial corrections from depending on users spotting problems one by one.

## Required output for every re-audited film

A film leaves provisional status only after the review records:

1. verdict + confidence
2. at least two concrete reasons
3. adversarial regional/social-media discovery pass
4. source-delta audit when based on real people/events
5. Narrative Integrity findings (or an explicit no-material-finding result)
6. Fact / Interpretation / Intent separation for sensitive findings
7. evidence trail
8. review depth and methodology version

The user should not be expected to discover missing adaptation or representation issues after publication.
